## 1. 개요

<!-- 이 모듈이 무엇이고 왜 만드는지 2~3줄 -->
8비트 병렬 데이터를 직렬 신호 한 가닥으로 변환해 송수신하는 모듈.
클럭선 없이 양쪽이 약속된 baud rate로 동작하는 비동기 방식.
전선 수를 줄이는 대신 타이밍 정확도가 요구된다.

| 약칭 | 8N1 |

## 3. 프레임 구조

<!-- 아래 다이어그램을 직접 그려보세요 -->
idle | start | D0 | D1 | D2 | D3 | D4 | D5 | D6 | D7 | stop | idle
1프레임 (총 10비트, 데이터 비트 8비트)

| 구간 | 값 | 길이 | 역할 |
|---|---|---|---|
| idle | 1 | 가변 (0비트 이상) | 아무것도 안 보내는 상태 |
| start bit | 0 | 1bit | idle과 반대 값을 주며 신호의 시작을 알림 |
| data | 8'h00 ~ 8'hFF | 8bit | 원하는 실제 8비트 데이터 값 |
| stop bit | 1 | 1bit | 프레임의 끝을 알리며 다음 start와의 구분 |

**idle이 1인 이유**: 
start bit 0이므로 1에서 0로 떨어지는 순간 데이터 신호가 온다는 것으로 구분하기 위해 1로 지정

**stop bit가 필요한 이유**: 
데이터들의 구분을 위한 지정, start bit가 0이기 때문에 1과 0의 신호 변경으로 데이터의 시작과 끝을 구분

## 4. 타이밍 파라미터

### 4-1. TX 분주비

| 항목 | 값 | 계산식 |
|---|---|---|
| 시스템 클럭 | 50 MHz | |
| 목표 baud rate | 9600 baud | |
| 분주비 (BAUD_DIV) | 5208 | 50,000,000/9600 = 5208.33...  →  5208 (내림) |
| 실제 baud rate | 9600.6 | 50,000,000/5208 |
| 오차 | 0.006 % | (9600.6-9600)/9600*100 |

### 4-2. RX 오버샘플링

| 항목 | 값 | 계산식 |
|---|---|---|
| 오버샘플링 배수 | 16배 | |
| 샘플 분주비 (SAMPLE_DIV) | 325 | 50,000,000/(9600*16) = 325.52  →  325 (내림) |
| 실제 baud rate | 9615.4 | 50,000,000/(325*16) |
| 오차 | 0.16 % | (9615.4-9600)/9600*100 |

**허용 오차 기준**: 
이론적 한계: 0.5비트 / 9.5비트 = 5.3%
  → RX는 start bit에서 한 번 동기를 맞추고 stop bit까지 9.5비트를
    자기 클럭으로만 진행. 누적 오차가 반 비트를 넘으면 인접 비트를 읽음

실무 목표: ±2% 이내
  → 송신 측과 수신 측 오차가 합산될 수 있으므로 여유를 둠

판정: TX 0.006%, RX 0.16% — 모두 목표 범위 내

**RX가 오버샘플링을 쓰는 이유**: 
데이터가 언제 올지 모르고, 비트 전환되는 가장자리에서 읽으면 불안정한 신호를 읽거나 클럭오차로 인접 비트를 읽을 수 있기에 비트 중앙을 읽기 위해 1비트를 여러개로 쪼개 비트 중앙을 읽는다
start bit 감지 후 8틱을 기다려 중앙에 정렬한다

**TX는 왜 필요 없는가**: 
TX는 자기가 정한 시점에 비트를 내보내기에 5208클럭마다 다음 비트를 출력하면 되는데
RX는 상대가 정한 시점을 알아내기에 필요하다
